# 验证报告

本地日期：2026-10-13。目标国服 7.56。验证基线：本机 Dalamud 15.0.3.6，SDK 15.0.0，.NET SDK 10.0.100。

## 已验证

- Release 构建零警告、零错误。
- 15 项核心测试：频道、收件人校验、UTF-8 分段及字符边界、句末优先、临界长度、控制字符、空结果、术语、两秒队列、角色变化、草稿保护、取消、错误不重试、留言匹配、SQLite 重启恢复/隔离/搜索/保留/已读/删除。
- 官方 ASR 模型样本 `test_wavs/0.wav`（16 kHz）运行真实 CPU 识别及 INT8 标点模型，输出：
  `对我做了介绍，那么我想说的是，大家如果对我的研究感兴趣呢。`
- 该测试首次模型加载及推理约 4.7 秒；这不是最终用户设备的性能保证，也不是正式准确率指标。
- 两个模型压缩包 SHA256 校验通过，固定约 133 MiB 下载量。
- 最终 ZIP 解压后，使用包内 DLL、原生依赖及随附模型执行 17 项测试（包含 SQLite、默认模型路径迁移与 ASR/标点推理），全部通过。安装包只保留 Windows x64 原生依赖，包含已解压的两个模型，约 135 MiB。
- 自动测试不录音、不向游戏发送聊天、不读取玩家真实私聊。

## 模型随包交付（2026-10-13）

- 用户反馈系统 tar 缺少外部 bzip2，要求模型在开发阶段下载并解压后，直接和插件一起交付。
- `scripts/prepare-models.py` 在构建机器下载固定官方压缩包、核验 SHA256 并解压；CI 显式安装 Python 3.12。插件运行时不下载、不解压模型，也不依赖 Python、tar、bzip2 或额外解压 DLL。
- ZIP 内的 `models` 包含两个完整模型目录、原始 README 和测试 WAV，共 19 个文件、约 153.6 MiB；ZIP 约 135 MiB，不包含模型压缩包。打包时强制检查五个必要的 INT8/词表文件。
- 插件默认读取自身目录内的 `models`；旧版配置目录下的默认路径自动切换，自定义路径保留，设置提供“使用随附模型”和“检查本地模型”。已移除下载入口及运行时安装器。
- Release 构建零警告、零错误。将最终 ZIP 解压到新目录，仅添加测试器，清空 PATH，通过 `--bundled` 使用默认路径读取包内模型；成功识别官方 WAV，全部 17 项测试通过。测试未引用工作区外部模型目录。
- 游戏内加载、录音及最终语音质量仍待用户验收。

## Dalamud 内存加载路径修复（2026-10-13）

用户反馈插件构造时 `Assembly.Location` 为空，导致模型目录拼接抛出 `ArgumentNullException`。模型目录与原生 DLL 目录均改由 Dalamud 的 `IDalamudPluginInterface.AssemblyLocation.DirectoryName` 显式传入，运行时代码不再读取程序集 Location。新增实际 `AssemblyLoadContext.LoadFromStream` 回归测试，验证空 Location 下的路径解析。Release 构建零警告、零错误；全部 18 项测试通过，包含真实 ASR/标点推理。游戏内重新加载仍待用户复测。
